# ShotFreeTRT image-generation brief

**Use:** ChatGPT WEB image generation in a separate asset thread.  
**Owner:** ShotFreeTRT brand system v1.0.  
**Output rule:** generate separate downloadable assets, never a contact sheet or a collage of the batch.

## Paste this instruction before every batch

Generate **10 separate images**, one image per numbered prompt below. Preserve the supplied order and use the requested filename as the download name where the interface allows it. Do not combine the images into a sheet, grid, carousel, or single document. The images are editorial assets for ShotFreeTRT, an evidence-led site helping men investigate low testosterone and TRT decisions.

**Shared style prefix for every prompt:**

> ShotFreeTRT editorial field-note illustration, precise simplified scientific drawing with one clear focal relationship, matte ink and carbon forms, bone-white and cobalt-blue focal marks, a tiny restrained brass accent, graphite contour texture at low opacity, optically balanced negative space, quiet premium health-journal aesthetic, no glossy plastic, no neon glow, no stock wellness look, no dramatic cinematic lighting, no identifiable person, no product branding, no medical drama, clean edges suitable for web cards.

**Shared constraints for every prompt:**

> Create exactly one standalone asset. Transparent background with a true alpha channel, no floor, no room, no sky, no frame, no drop shadow extending beyond the subject, no border, no watermark, no logo, no generated words, no letters, no numbers, no labels, no illegible pseudo-text, no citations, no UI screenshot. Keep all important forms inside the canvas with generous transparent padding. Use a restrained four-color palette: `#090B10`, `#111722`, `#2E5FA7`, `#E9E5DA`, with `#C7A86B` as a small accent only. Add labels and captions later in HTML/SVG.

For anatomical or physiological subjects, use a high-level educational cutaway with correct relative relationships and no claim about an individual patient. Do not imply that any treatment guarantees an outcome. If transparent export is unavailable, stop and ask for a rerender with alpha; do not substitute a white or noisy background. Return the image files individually and report the final pixel dimensions and whether alpha is present.

## Batch-level review gate

Accept an asset only when it meets all of these checks:

- It is a separate file with the requested dimensions and a verified alpha channel.
- Its subject is recognizable at card size and communicates one idea without generated text.
- It uses the ShotFreeTRT palette and line/texture language without a neon gradient, glossy 3D look, stock wellness pose, or fake clinical authority.
- It does not depict a diagnosis, guaranteed treatment result, fertility preservation, lifespan extension, or provider endorsement.
- The proposed alt text is factual and the page caption carries any needed medical nuance.
- The web derivative is compressed, the original master is retained, and the asset has a route/owner in the coverage manifest.

If any image misses the style, request a targeted rerender by naming the asset ID and the failed constraint. Do not “fix” it with a global style change that breaks the rest of the batch.
